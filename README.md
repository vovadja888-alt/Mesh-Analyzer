# Meshanalyzer — ПЗ для аналізу та виявлення помилок 3D-моделей

Настільний застосунок на Python 3 (архітектура MVC, інтерфейс CustomTkinter) для синтаксичного розбору, геометричної валідації та 2D-візуалізації 3D-моделей формату Wavefront OBJ.

## Встановлення та запуск
```bash
pip install -r requirements.txt
python Main.py
